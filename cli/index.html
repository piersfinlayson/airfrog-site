Example usage

# List Airfrogs on the network
$ airfrog scan
Scanning the network ...
found 1 Airfrog:
  airfrog.local 192.168.1.21

# Install firmware on a Pico from a UF2 file
$ airfrog target program --firmware blink.uf2 --verify
Programming target...
Verification passed
Programming complete

Use airfrog --help to display commands.

Features

  • List Airfrogs on the network
  • Update Airfrog firmware
  • Change Airfrog settings
  • Manage extensions
  • Read and modify the connected microcontroller
  • Install firmware on an RP2040 or RP2350 from a UF2 file
