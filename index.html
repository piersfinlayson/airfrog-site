Tiny WiFi co-processor for microcontrollers

Adds WiFi and co-processing to almost any microcontroller, so you can control it from a browser or command line.
Fully open source.

Get started

Add to Airfrog's capabilities with extensions. Write your own or install from the managed repository, including:

ExtensionDescription
